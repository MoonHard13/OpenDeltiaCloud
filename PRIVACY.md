# Privacy Policy

Effective date: 2026-05-28

OpenDeltiaCloud is a desktop utility for internal business use. This Privacy Policy explains what data the application uses and how Google Drive access is handled.

## Data the application uses

OpenDeltiaCloud may read and write the following files in a Google Drive folder used by the application:

- `fnb_afm_keys.txt`
- `fnb_comments.json`
- `fnb_company_comments.json`
- `fnb_pins.json`
- `fnb_layout.json`

These files may contain business configuration data, AFM / VAT numbers, API keys, company names, document comments, company comments, pinned document identifiers, and interface layout settings.

## Google Drive access

OpenDeltiaCloud uses Google Drive only to synchronize the application files listed above. The application is intended to access the Google Drive folder used for OpenDeltiaCloud synchronization.

The application does not intentionally read, modify, share, or delete unrelated Google Drive files.

## Local storage

OpenDeltiaCloud may store local cache and credential files on the user's computer so the application can continue working when Google Drive is unavailable and so the user does not need to sign in every time.

Local files may be stored under the user's profile folder, for example:

`C:\Users\<User>\.moonhard\`

## How data is used

The data is used only for the following purposes:

- loading AFM / VAT and API key configuration,
- displaying and saving document comments,
- displaying and saving company comments,
- synchronizing pinned document markers,
- restoring application layout and preferences,
- keeping multiple authorized computers synchronized.

## Data sharing

OpenDeltiaCloud does not sell user data. OpenDeltiaCloud does not share user data with advertisers. Data stored in Google Drive is controlled by the Google account and Google Drive folder permissions configured by the user or organization.

## Data deletion

Users can delete synchronized data by removing the OpenDeltiaCloud files from the Google Drive folder and by deleting the local cache files from their computer.

Users can revoke Google Drive access from their Google Account security settings at any time.

## Security

Users are responsible for protecting the Google Drive folder permissions and for keeping API keys secure. Only trusted users should be given access to the OpenDeltiaCloud Google Drive folder.

## Contact

For privacy questions, contact the project maintainer through the GitHub repository owner profile.
